## 🚀 ចាប់ផ្តើមប្រើ (Quick start)

### Windows
1. Unzip folder នេះ ទៅកន្លែងដែល**មិនមែនក្នុង OneDrive / Desktop** (ឧ. `C:\V_Heang_Studio`) — OneDrive នឹង sync ឯកសារធំៗ ហើយធ្វើឲ្យយឺត
2. **ចុចពីរដងលើ `start.bat`** (បើ Windows ថា “Windows protected your PC” → **More info → Run anyway**)
3. ចាំ ១–៣ នាទីលើកដំបូង (ដំឡើង packages) — Browser នឹងបើកដោយស្វ័យប្រវត្តិនៅ <http://127.0.0.1:8000>
4. បិទ៖ ចុច **Ctrl+C** ក្នុងបង្អួចខ្មៅ (ឬបិទបង្អួចនោះ)
> បើ Windows បើក **Microsoft Store** ពេលចុច `start.bat` — នោះគ្រាន់តែជា shortcut ទេ មិនមែន Python ពិតទេ។ បិទ Store ហើយដំឡើង Python ពី python.org (tick “Add python.exe to PATH”)។

### 🍎 macOS (MacBook · iMac · Mac mini)
1. ដំឡើង **Python 3.10+** តែម្តង៖ ទាញ installer ពី <https://www.python.org/downloads/macos/> ហើយបើកវា (ឬ `brew install python@3.12`)
2. Unzip folder នេះ (ទុកក្នុង Downloads ឬ Home ក៏បាន)
3. **ចុចពីរដងលើ `start.command`** — បង្អួច Terminal បើក ហើយ Browser បើកដោយស្វ័យប្រវត្តិនៅ <http://127.0.0.1:8000> (លើកដំបូង ១–៣ នាទី ដំឡើង packages)
   - លើកដំបូង macOS អាចថា “cannot be opened because Apple cannot check it for malicious software” (**Gatekeeper** — ឯកសារទាញពី Internet)៖
     - **macOS 14 ឬចាស់ជាងនេះ** → ចុចខាងស្តាំលើ `start.command` → **Open** → **Open**
     - **macOS 15 ឬថ្មីជាងនេះ** → **System Settings → Privacy & Security** → ទាញចុះក្រោម → **Open Anyway**
   - **ឬចៀសវាងការព្រមានទាំងអស់៖** បើក **Terminal** វាយ `cd ` (មានចន្លោះ) ទាញ folder V_Heang Studio ទម្លាក់ចូលបង្អួច Terminal ចុច Enter រួចវាយ `sh start.sh` ចុច Enter
4. បិទ៖ ចុច **Control + C** ក្នុង Terminal (ឬបិទបង្អួច Terminal)

លើកក្រោយៗ គ្រាន់តែចុចពីរដងលើ `start.command` ម្តងទៀត។ មើលផ្នែក **🍎 macOS — ចំណាំ** សម្រាប់ VoxCPM2, Cookies និងបញ្ហាដែលអាចកើតមាន។

2. ចុចប៊ូតុង **ដំឡើងជា App** ក្នុងម៉ឺនុយខាងឆ្វេង (ក្រោម ការកំណត់)។

**ត្រូវដឹង (សំខាន់)**
- ⚠ **App ដំឡើងមិនអាចបើក server ឲ្យបានទេ** — ព្រោះ V_Heang Studio រត់លើកុំព្យូទ័ររបស់អ្នក។ ត្រូវរត់ `start.bat` / `start.command` **ជាមុន** ដូចដើម (ទុកផ្ទាំងខ្មៅ / terminal បើក)។ បើភ្លេច → App បង្ហាញទំព័រ «**មិនទាន់ដំណើរការទេ**» (ខ្មែរ + English) ប្រាប់ឲ្យ start។ ទុកទំព័រនោះបើក — ពេល server ត្រៀមរួច វា**បើក dashboard ដោយខ្លួនឯង** (ពិនិត្យរៀងរាល់ ~២.៥ វិនាទី)។

  - បើបើក `start.bat` ពីរដង៖ ពេល 8000 ជាប់ដោយ V_Heang Studio **កំណែដដែល** → server.py **មិនចាប់ផ្តើមច្បាប់ចម្លងទី ២ លើ 8001 ទេ** គ្រាន់តែបើក app ដែលកំពុងរត់។ បើ 8000 ជាប់ដោយកម្មវិធីផ្សេង ឬ V_Heang Studio កំណែផ្សេង → ប្រើ port បន្ទាប់ (8001 …) ដូចមុន — App ដំឡើងនឹងមិនបើកកំណែនោះទេ (address ខុស)៖ បិទកម្មវិធីចាស់ រួចបើកម្តងទៀត។

4. **Output**
   - *តម្រឹម Timing*: **តម្រឹមតាមវីដេអូ** (ឃ្លាខ្មែរនីមួយៗចាប់ផ្តើមត្រូវពេលនឹងវីដេអូដើម) ឬ **ធម្មជាតិ** (គ្មាន sync)

   - *គុណភាពវីដេអូ MP4* (បង្ហាញពេលជ្រើស MP4)៖ **1080p** (លំនាំដើម) ឬ **720p** — វីដេអូត្រូវបានទាញយកពី YouTube ក្នុងកម្ពស់អតិបរមានោះ (បើវីដេអូដើមទាបជាងនេះ នឹងបានតាមដែលវាមាន)។ 1080p ធំជាង និងទាញយកយូរជាង 720p ប្រហែល ២–៣× (វីដេអូគំរូ ៣.៥ នាទីដែលខ្ញុំសាកល្បង៖ MP4 1080p = 83 MB · 720p = 29 MB)។ បើប្តូរគុណភាពក្រោយមក ពេល *Regenerate* ប្រព័ន្ធទាញយកម្តងទៀត ដើម្បីឲ្យ MP4 ត្រូវតាមការជ្រើសរើស។ Log បង្ហាញទំហំពិត (ឧ. `Video: 1920×1080 h264`) ហើយលទ្ធផលបង្ហាញ *MP4 1080p*។ ប្រសិនបើវីដេអូដើមមិនមែន H.264 ការបញ្ចូលសំឡេង (mux) ត្រូវ encode ឡើងវិញ (យឺតជាង)។
   - *បិទសំឡេងដើម ពេលសំឡេងខ្មែរកំពុងនិយាយ* (បើកជាលំនាំដើម)៖ ក្នុងរយៈពេលដែលអ្នកនិយាយដើម **ឬ** សំឡេងខ្មែរកំពុងនិយាយ សំឡេងដើមត្រូវបានបិទទាំងស្រុង (មាន fade ខ្លី គ្មានសំឡេង “ក្រេប”) ហើយត្រឡប់ទៅកម្រិតដែលបានកំណត់ក្នុងចន្លោះឃ្លា។ គ្មានប្រសិទ្ធភាពបើ Original video audio = 0

- **ផ្ទាំង «តួអង្គ (ចាប់ពីសំឡេងដើម)»** (ក្នុងលទ្ធផល ខាងលើតារាង)៖ តួអង្គនីមួយៗ = ស្លាក ♂ 1 / ♀ 2 · ឈ្មោះ (មិនបង្ខំ) · ចំនួនជួរ · **Voice** (ជម្រើសទីមួយ «ស្វ័យប្រវត្តិ — ពិសិដ្ឋ» ប្រាប់អ្វីដែលនឹងនិយាយពិតៗ) · **⇄** ប្តូរភេទ។ ក្នុងតារាង ស្លាក ♂ / ♀ + លេខតួអង្គ នៅក្រោមលេខជួរ (ស្លាកព្រុយ = មិនប្រាកដ)។ ការប្តូរណាមួយ (ភេទ · Voice · ឈ្មោះ) រាប់ជា «បានកែ» → ចុច **«បង្កើតសំឡេងឡើងវិញ»**។ ប៊ូតុង **ស្គាល់តួអង្គ / ម្តងទៀត** ប្រើជាមួយការងារចាស់ ឬការងារដែលបិទមុខងារនេះពេលបង្កើត។
- **បើកម្មវិធីស្មានខុស**៖ ① ចុច **⇄** លើតួអង្គ (ក្មេង · សំឡេងនៅចន្លោះប្រុស/ស្រី) ② ឬជ្រើស Voice ឲ្យតួអង្គ ③ ឬជ្រើស Voice ឲ្យ**ជួរ** (ឈ្នះជានិច្ច) ④ ឬបិទ switch។
- **វាដំណើរការយ៉ាងដូចម្តេច (ឲ្យដឹងថាទុកចិត្តបានប៉ុណ្ណា)**៖ វាស់ **ល្បឿនញ័រនៃសំឡេង (pitch / F0)** — ប្រុសជាធម្មតា 85–180 Hz ស្រី 165–255 Hz — មិនមែន AI model ទេ ដូច្នេះ**មិនត្រូវដំឡើងអ្វីថ្មី**។ ជួរដែលសំឡេងស្រដៀងគ្នាចែករំលែកភស្តុតាង; ភេទតែ ១–២ ជួរដែលឃ្លាតពីអ្វីផ្សេងត្រូវដើរតាមវីដេអូ; បើសំឡេងមិនច្បាស់ (តន្ត្រី · ខ្សឹប — < ២០% នៃពេលនិយាយអាចវាស់) → **មិនស្មាន** ហើយប្រើ Voice ដែលអ្នកបានជ្រើស (មានការព្រមាន)។ **តួអង្គ** = ក្រុមជួរដែលសំឡេងដូចគ្នាក្នុងភេទតែមួយ — **ប្រុងប្រយ័ត្ន**៖ ចូលចិត្តបញ្ចូលបុរសពីរនាក់ជាមួយគ្នា (ពួកគេប្រើសំឡេងតែមួយ) ជាងបំបែកមនុស្សម្នាក់ជាពីរ។
- **ភាពត្រឹមត្រូវ (វាស់ ពុំមែនសន្យា)**៖ សំឡេងមនុស្សពិត (FLEURS ៖ ខ្មែរ · English · 中文 · 한국어) ឃ្លាពេញ **98.9%** · ជួរ ២–៦ វិនាទី **96.6%** (ជាមួយសំឡេងរំខាន 10 dB **94.3%** · តន្ត្រី 10 dB **88.4%** មុនចែករំលែកភស្តុតាង) · វីដេអូប្រមូលពីឃ្លាទាំងនោះ **97.9%** (តន្ត្រី 5 dB **77.9%**) · អ្នកនិយាយ LibriSpeech **39 / 39** · សំឡេង Microsoft Neural **32 / 32** · dub ខ្មែររបស់កម្មវិធីខ្លួនឯង **24 / 24**។ **ខុសជាងនេះ**ចំពោះ៖ ក្មេង (សំឡេងខ្ពស់ → ស្រី) · បុរសស្រែក / សុន្ទរកថាដែលសំឡេងឡើងដល់ ~250 Hz · សំឡេង 150–180 Hz (≈ ៨០%) · ច្រៀង · តន្ត្រីខ្លាំង · ពីរនាក់និយាយជាន់គ្នា។ មិនទាន់សាកជាមួយ YouTube ពិតដែលមានតន្ត្រី / សំឡេងរំខាន — ពិនិត្យតារាង។
- **ដែនកំណត់សំខាន់៖ កម្មវិធី «ស្តាប់» ទើបដឹងថាអ្នកណានិយាយ** — បំបែកបានតែអ្វីដែលមានក្នុង**សំឡេង**។ ① មនុស្សច្រើននាក់និយាយពិត (សន្ទនា · សម្ភាសន៍ · ភាពយន្ត) → កម្មវិធីរកឃើញតួអង្គតាមភេទ។ ② បើ **អ្នកនិទានម្នាក់អានរឿងទាំងមូល** (ដូចវីដេអូរឿងនិទានជាច្រើន — ហើយអានតួអង្គផ្សេងៗដោយសំឡេងខ្លួនឯង) សំឡេងមានតែ ១ → កម្មវិធីរកឃើញ **១ តួអង្គ** ហើយ**មិនអានអត្ថបទ**ដើម្បីទាយថាអ្នកណានិយាយ — ជ្រើស **Voice ក្នុងមួយជួរ** (ឬធីកច្រើនជួរ → ជ្រើស Voice → *ដាក់*) ដោយដៃ។ ③ **ប្រុសពីរនាក់ ឬស្រីពីរនាក់** ភាគច្រើនត្រូវបញ្ចូលគ្នា (សំឡេងស្តាប់ស្រដៀងគ្នា) ហើយ Edge មានសំឡេងខ្មែរតែ ២ (ពិសិដ្ឋ · ស្រីមុំ) → តួអង្គភេទដូចគ្នាប្រើសំឡេងដូចគ្នា; **VoxCPM2** អាចឲ្យតួអង្គនីមួយៗមានសំឡេងផ្ទាល់ខ្លួន (Clone ពីសំឡេងដើមរបស់ខ្លួន ឬ Designed voice ដល់ ៤ ក្នុងមួយភេទ)។

#### ⏱ Start / End ក្នុងមួយជួរ
- ក្នុងជួរនីមួយៗមានប្រអប់ម៉ោង **Start** (ពេលសំឡេងខ្មែរចាប់ផ្តើម) និង **End** (ពេលដែលវាគួររួច)។ វាយ `2:14.5` ឬ `134.5` ឬចុច **↑ / ↓** (±0.1 វិនាទី · Shift = ±1 វិនាទី)។ ម៉ោងដែលអ្នកកែមានស៊ុមពណ៌ — ម៉ោងដែលមិនកែប្រើម៉ោងពី Caption (ដូចមុន)។ ប៊ូតុង ↺ ត្រឡប់ទៅម៉ោងដើម។
- **ពេលវេលាត្រូវបានចែកដូចម្តេច?** ជួរដែលមិនកំណត់ End ប្រើពេលរហូតដល់ *Start នៃជួរបន្ទាប់ − 0.1 វិនាទី*។ ដូច្នេះបើជួរទី ៣ ត្រូវបង្កើនល្បឿនខ្លាំង (×1.31) សូម**ដាក់ Start នៃជួរទី ៤ ឲ្យយឺតជាងមុន** — ជួរទី ៣ ទទួលបានពេលនោះដោយស្វ័យប្រវត្តិ។ ឬដាក់ Start នៃជួរទី ៣ ឲ្យលឿនជាងមុន បើជួរទី ២ និយាយរួចមុន។
- **ពណ៌នៃល្បឿន** (បង្ហាញក្បែរម៉ោង ហើយប្តូរភ្លាមៗពេលអ្នកកែម៉ោង ឬអត្ថបទ)៖ **បៃតង** ≤ ×1.15 · **លឿង** លឿនជាងនោះ តែនៅក្នុងដែនកំណត់ (Settings → Audio, លំនាំដើម ×1.40) · **ក្រហម ✕** មិនគ្រប់ទោះបង្កើនល្បឿនអតិបរមា → ពង្រីកពេល ឬកាត់អត្ថបទ។ “≈” = ប៉ាន់ស្មានតាមប្រវែងអត្ថបទថ្មី (ត្រឹមត្រូវក្រោយ Regenerate)។ ក្រោយ Regenerate ជួរដែលនៅតែវែងពេកមានស្លាក **វែងពេក**។
- ប៊ូតុង **↔ ពង្រីកពេល**៖ ប្រើពេលទំនេរក្រោយជួរនេះ (រហូតដល់ជួរបន្ទាប់) ហើយបើនៅមិនគ្រប់ ប្រើពេលទំនេរមុនជួរនេះ (ក្រោយជួរមុននិយាយរួច) — មិនប៉ះពាល់ជួរជិតខាងទេ។
- **ដែនកំណត់៖** ម៉ោងប្រើបានតែក្នុងរបៀប *តម្រឹមតាមវីដេអូ* ជាមួយវីដេអូ/SRT ដែលមាន timestamp (របៀប *ធម្មជាតិ* ដាក់ឃ្លាតាមលំដាប់ ដូច្នេះមិនអើពើម៉ោង)។ ម៉ោងដែលអ្នកកំណត់មិនប្តូរ SRT ភាសាដើម (`original.srt`) ទេ — វាប្តូរតែ `khmer.srt` និងសំឡេង។ បើ End ខ្លីពេក ហើយសំឡេងវែង → ល្បឿនកើនដល់អតិបរមា ហើយអ្វីដែលនៅសល់រុញជួរបន្ទាប់ (បើរុញលើស ២.៥ វិនាទី ជួរនោះមានស្លាក *យឺត*)។

វីដេអូពីកន្លែងផ្សេង (ជាពិសេសវីដេអូចិន / កូរ៉េ) ច្រើនមាន **Subtitle បោះពុម្ពជាប់ក្នុងរូបភាព** (hard-sub)។ ពេលដាក់សំឡេងខ្មែរ Subtitle ចាស់នោះនៅតែឃើញ ហើយជាន់ Subtitle ខ្មែរ។ មុខងារនេះធ្វើឲ្យវា **មើលមិនច្បាស់** ក្នុង MP4 (Subtitle ខ្មែររបស់កម្មវិធី មិនត្រូវប៉ះពាល់ទេ)។

1. ក្នុង **Step 4 · Output** ជ្រើស **MP3 + MP4 Video** → បើក switch **បិទបាំង Subtitle ដើម**។

**មានការងារស្រាប់ហើយ?** ក្នុងលទ្ធផល ប្រអប់ **ទម្រង់ Video (TikTok) · Subtitle ដើម** → ប្តូរ switch / Effect / ទីតាំង → **បង្កើត Video ឡើងវិញ** (សំឡេងខ្មែរ និងការកែរបស់អ្នកមិនប៉ះពាល់)។ ប្រអប់ចាប់ផ្តើមពីអ្វីដែល MP4 មានពិត។

**ចំណាំ៖**
- ពេលបើក រូបភាព **ត្រូវ encode H.264 ឡើងវិញ** (យឺតជាង); ពេលបិទ MP4 នៅតែចម្លងរូបភាពដូចមុន។ ដំណើរការជាមួយ **TikTok 9:16** ផង (band ធ្វើមុន ស៊ុម 9:16 ធ្វើក្រោយ)។
- កំណត់ band **ដោយដៃ** (មិនទាន់រកទីតាំង Subtitle ដោយស្វ័យប្រវត្តិ); band ពេញទទឹងរូបភាព។ **HDR** មិនទាន់បម្លែងពណ៌។ វីដេអូ YouTube ក្នុង Sync Preview ជា iframe → ស្មានថារូបភាព 16:9។
- មុខងារនេះ **លាក់តែអក្សរលើអេក្រង់** — វាមិនប្តូរម្ចាស់សិទ្ធិវីដេអូ ហើយមិនធានាអ្វីអំពី copyright claim (សំឡេង និងរូបភាពដែលនៅសល់ មិនប្តូរ)។

#### 🤖 បកប្រែជាមួយ Claude (Copy / Paste)

6. ចុច **បង្កើតសំឡេង** (របារខាងក្រោម) → កម្មវិធីអានអត្ថបទខ្មែរនោះ (Edge ឬ VoxCPM2) ហើយបង្កើត MP3 / MP4 / SRT ដូចធម្មតា។ ជួរដែលនៅទទេនឹងស្ងាត់ (កម្មវិធីសួរមុន); បើទទេទាំងអស់ → មិនចាប់ផ្តើម។

- ជ្រើស **ជួរក្នុងមួយដង** (20 · 40 · 80 · ទាំងអស់; លំនាំដើម 40)។ ប៊ូតុង ◀ ▶ ប្តូរផ្នែក។ ចម្លើយរបស់ Claude មានដែនកំណត់ប្រវែង — ផ្នែកខ្លីជួយកុំឲ្យចម្លើយដាច់។
- ពេលផ្នែកមួយ**ពេញ** កម្មវិធីរៀបចំផ្នែកបន្ទាប់ដោយខ្លួនឯង (ប្រអប់ Paste ត្រូវសម្អាត) → ចុច Copy ម្តងទៀត។ ចម្លើយអាចមកជាច្រើនដុំ (ឧ. Claude ដាច់ ហើយអ្នកប្រាប់ឲ្យ “continue”) — ជួរដែលបានបញ្ចូលនៅដដែល ហើយកម្មវិធីប្រាប់ថាជួរណាខ្វះ។
- **ឈ្មោះមនុស្ស**៖ **Latin** (លំនាំដើម — ដូចដើម) ឬ **អក្សរខ្មែរ** (សរសេរតាមសំឡេងជាខ្មែរ)។ ចាំជម្រើស។

**អ្វីដែលមានក្នុងអត្ថបទដែល Copy**
- ការណែនាំជាភាសា English សម្រាប់ AI៖ បកប្រែជាខ្មែរនិយាយធម្មជាតិ (សម្រាប់សំឡេង) · រក្សាលេខជួរដដែល · **រក្សាពាក្យបច្ចេកទេស ឈ្មោះ product acronym និងលេខ ជា English** (រួមទាំងបញ្ជីពាក្យដែលរកឃើញក្នុងផ្នែកនោះ ពី Technical Terms របស់អ្នក; សម្រាប់ 中文 / 한국어 ជាទម្រង់ “服务器 → server”) · ខ្លីប្រហាក់ប្រហែលនឹងដើម (ឲ្យសមពេល) · ឆ្លើយជា code block តែមួយ មានតែជួរមានលេខ។
- ជួរ subtitle មានលេខដូចក្នុងតារាង និងឈ្មោះវីដេអូ (បើមាន)។ បើអ្នកបិទ *រក្សាពាក្យបច្ចេកទេសជា English* ការណែនាំប្តូរទៅ “បកប្រែទាំងអស់”។
- **ឬ Copy តែ៖ ការណែនាំ / ជួរមានលេខ** — សម្រាប់ **Claude Project**៖ ដាក់ការណែនាំម្តងក្នុង Project រួច Paste តែជួរមានលេខរាល់ពេល (ខ្លី និងលឿន)។
- បើប៊ូតុង Copy មិនដំណើរការ (Browser ហាមឃាត់) → ចុច **មើលអត្ថបទដែលនឹង Copy** រួចជ្រើសអត្ថបទ + Ctrl+C។

**ការអានចម្លើយ**
- អានបានទាំងក្នុង code block និងអត្ថបទធម្មតា៖ `1.` `1)` `1:` `1 -` `[1]` `(1)` `**1.**` `Line 1:` `ជួរទី 1:` និងលេខខ្មែរ (`១.`)។ ជួរវែងដែល Claude បំបែកជាច្រើនបន្ទាត់ត្រូវភ្ជាប់វិញ; Markdown (`**bold**` និង `` `code` ``) ត្រូវលុប; ពាក្យពន្យល់មុន/ក្រោម code block ត្រូវមិនអើពើ។
- បើគ្មានលេខសោះ ប៉ុន្តែចំនួនបន្ទាត់ត្រូវនឹងផ្នែកដែលបានសុំ → បញ្ចូលតាមលំដាប់ (មានប្រកាស)។ បើមិនត្រូវ → មិនទាយ (ប្រាប់ឲ្យសុំ Claude ឆ្លើយជា `1. …`)។
- កម្មវិធីរាយការណ៍៖ ជួរដែលបានបញ្ចូល · **ជួរខ្វះ** · ចម្លើយ**ដាច់** (ប្រាប់ឲ្យសុំ Claude បន្ត) · ជួរ**គ្មានអក្សរខ្មែរ** (Claude ទុកជា English) · លេខ**ស្ទួន** · លេខមិនមាននៅក្នុងការងារ។

**ជាមួយការងារដែលមានស្រាប់ (Google / LLM បានបកប្រែរួច)**
- ប្រអប់តែមួយដដែលនៅក្នុងកាត **កែអត្ថបទបកប្រែ (Segments)** នៃលទ្ធផលណាមួយ (បិទជាលំនាំដើម — ចុចដើម្បីបើក)។ ចម្លើយរបស់ Claude ជំនួសជួរក្នុងតារាងជា “ការកែ” (ខ្សែលឿង — មិនទាន់រក្សាទុករហូតចុច **បង្កើតសំឡេងឡើងវិញ**) ដូច្នេះអាចប្រៀបធៀប Google និង Claude ជួរម្តងមួយ។

**ការពារការងារ**
- ការងារ **ព្រាង** មានស្លាក “ព្រាង” ក្នុង History។ បើការបង្កើតសំឡេងលើកដំបូងបរាជ័យ (ឧ. អ៊ីនធឺណិតដាច់) ព្រាងនៅដដែលជាមួយអត្ថបទខ្មែររបស់អ្នក — ចុច “បង្កើតសំឡេង” ម្តងទៀត។
- ការងារព្រាង + MP4 ពី YouTube៖ វីដេអូត្រូវបានទាញយកពេលចុច “បង្កើតសំឡេង” (មិនមែនពេលត្រៀមអត្ថបទ) តាមការកំណត់ Output នៅពេលនោះ។

#### 📌 វីដេអូ Fixed នៅខាងស្តាំ (Dock) · ម៉ឺនុយរុញចេញចូល
- **Sync Preview (YouTube)** និង **MP4 video** ត្រូវបាន **Fixed នៅខាងស្តាំអេក្រង់** (ក្រោមចំណងជើង) ដូច្នេះអ្នកអាចរំកិលចុះទៅតារាង *Segments* ហើយនៅតែឃើញវីដេអូ + Subtitle + ប៊ូតុងបិទ/បើក (Subtitle ដើម · Subtitle ខ្មែរ · សំឡេងដើម · បិទសំឡេងដើម) ពេលកំពុងចាក់។ ទំព័រទុកកន្លែងខាងស្តាំឲ្យ ដូច្នេះតារាងមិនរត់ក្រោមវីដេអូទេ។
- **ម្តងមួយ**៖ ផ្ទាំង Fixed មានតែមួយ — ពេលបើក **Sync Preview** វាយកកន្លែង ហើយ MP4 video ត្រឡប់មកក្នុងទំព័រជាបណ្តោះអាសន្ន; ពេលបិទ Sync Preview (✕) MP4 video ត្រឡប់ទៅ Fixed វិញ។ ជាមួយការងារ MP3 (គ្មាន MP4) ផ្ទាំង Fixed មានតែពេលបើក Sync Preview។
- ប៊ូតុងក្នុងក្បាលផ្ទាំង៖ **–** (បង្រួមឲ្យនៅតែរបារចំណងជើង) · **📌** (ដោះចេញ = ត្រឡប់ទៅក្នុងទំព័រ; ចុចម្តងទៀត = Fixed) · **✕** (បិទ Sync Preview)។ ជម្រើសទាំងនេះត្រូវបានចាំក្នុង browser។
- **បង្អួចតូច៖** ផ្ទាំង Fixed ត្រូវការទទឹង ≥ **1180 px**។ លើបង្អួចតូចជាងនេះ និងលើ Mobile វីដេអូនៅក្នុងទំព័រដូចមុន។
- **ម៉ឺនុយខាងឆ្វេង (☐)៖** ប៊ូតុងនៅខាងឆ្វេងចំណងជើង — ចុចដើម្បី **រុញម៉ឺនុយចេញ** (មាតិកាពង្រីកពេញអេក្រង់; តារាងបានទទឹងបន្ថែម ~២៦០ px) ហើយចុចម្តងទៀតដើម្បី**រុញចូលមកវិញ**។ ចាំជម្រើស ហើយពេលបើក Dashboard ម៉ឺនុយនៅដូចដែលអ្នកទុក (មិនលោត)។ ពេលម៉ឺនុយលាក់ ប៊ូតុងក្នុងម៉ឺនុយមិនអាចចូលដោយ Tab ទេ។ លើ Mobile ម៉ឺនុយនៅជាបន្ទាត់ខាងលើជានិច្ច។
- ជាមួយម៉ឺនុយបើក + វីដេអូ Fixed ជួរមាតិកាតូច ដូច្នេះប្រអប់ *2 · ជ្រើស Voice* និង *3 · ការបកប្រែ* ត្រូវបានរៀបចុះក្រោមគ្នា; រុញម៉ឺនុយចេញ → ពួកវាត្រឡប់ទៅរៀបជាពីរជួរ ហើយតារាង Segments ប្តូរទៅទ្រង់ទ្រាយទទឹង (ម៉ោង · ភាសាដើម · ខ្មែរ ក្នុងមួយជួរ)។

### 2) Text to Speech
វាយ ឬ paste អត្ថបទ → ជ្រើស *អត្ថបទខ្មែរ*, *English → ខ្មែរ*, *中文 → ខ្មែរ* ឬ *한국어 → ខ្មែរ* → ជ្រើសសំឡេង → **បង្កើតសំឡេង** → ទាញយក MP3។ ពាក្យ English ក្នុងប្រយោគខ្មែរ (ឧ. API, Dashboard) ក៏ត្រូវបានអានត្រឹមត្រូវដែរ។

### 3) ពាក្យបច្ចេកទេស (Technical Terms)
បញ្ជីពាក្យដែលត្រូវរក្សាជា English — **មួយពាក្យក្នុងមួយបន្ទាត់**៖
```text
# comment
API
machine learning
VS Code
nginx = អេនជីនអិច      ← រក្សា “nginx” ជា English ក្នុងអត្ថបទ ប៉ុន្តែអានតាមការអានខ្មែរនេះ
机器学习 => machine learning   ← (វីដេអូ 中文 / 한국어) ពាក្យដើម => ពាក្យ English ដែលត្រូវនៅក្នុងអត្ថបទខ្មែរ
```
- ការផ្គូផ្គងមិនប្រកាន់ អក្សរធំ/តូច ហើយទទួលយក plural (`APIs`) និង version (`GPT-4`, `Python3`)
- ប៊ូតុង Export / Import សម្រាប់ចែករំលែកបញ្ជី
- ការរកឃើញដោយស្វ័យប្រវត្តិ (CamelCase, ALL CAPS, `Node.js`, `4K`, `C++` …) អាចបិទបាន
- បន្ទាត់ `ពាក្យដើម => English` (អាចសរសេរច្រើនទម្រង់ដោយ `|`៖ `机器学习 | 機器學習 => machine learning`) ត្រូវបានប្រើតែពេលវីដេអូជា 中文 / 한국어 ហើយឈ្នះតារាងដែលភ្ជាប់មកជាមួយ។ បន្ទាត់ទាំងនេះមិនរាប់ជា “ពាក្យ” ទេ

## 🌏 ភាសាចិន និងកូរ៉េ (中文 · 한국어)

ពីជំហាន 1 ជ្រើស **ភាសាក្នុងវីដេអូ**៖

| ជម្រើស | ការប្រើប្រាស់ |
|---|---|
| **Auto-detect** (លំនាំដើម) | YouTube៖ ប្រព័ន្ធមើលថា captions ស្វ័យប្រវត្តិ (auto-generated) ជាភាសាអ្វី — វាតែងតែជាភាសាដែលអ្នកនិយាយ។ បើមានតែ manual captions ច្រើនភាសា ចំណងជើងវីដេអូ (ជាអក្សរចិន/កូរ៉េឬទេ) ជួយសម្រេច បើមិនដូច្នោះទេយក English → 中文 → 한국어។ អត្ថបទ/SRT៖ ស្គាល់តាមអក្សរ |
| **English / 中文 / 한국어** | ប្រើ captions ភាសានោះប៉ុណ្ណោះ (លឿន និងច្បាស់ជាង) |

**របៀបស្គាល់ភាសា** (សម្រាប់អត្ថបទ)៖ Hangul → Korean · Han (汉字) → Chinese · Latin → English។ ភាសាចិន/កូរ៉េតែងមានពាក្យ English ច្រើន (Docker, API…) ដូច្នេះគ្រាន់តែ ≥ ៨% នៃអក្សរជា 汉字/한글 ក៏រាប់ជា 中文/한국어 ហើយ។ **អក្សរនៃអត្ថបទឈ្នះជម្រើសរបស់អ្នក** (ជ្រើស English តែ paste 한국어 → ប្រើ Korean ហើយសរសេរក្នុង log) ពីព្រោះបកដោយភាសាប្រភពខុសឲ្យលទ្ធផលគ្មានន័យ។

**អ្វីដែលប្រព័ន្ធធ្វើខុសគ្នាតាមភាសា**៖
- **Captions**៖ ប្រើតែ track ដែលជាភាសារបស់វីដេអូពិតប្រាកដ — មិនប្រើ track ដែល YouTube បកដោយម៉ាស៊ីនទេ (ឧ. English ដែលបកពី Korean)។ 中文៖ 简体 មុន 繁體។
- **សម្អាត**៖ `[音乐]` `【掌声】` `（笑）` `[음악]` `(박수)` `(웃음소리)` ត្រូវលុប។ ប្រយោគចិនបញ្ចប់ដោយ `。！？`។
- **ប្រវែងឃ្លា (segment)**៖ English ≤ 230 តួ · 中文 ≤ 80 តួ · 한국어 ≤ 125 តួ (និង ≤ ~12 វិនាទី) ហើយមិនដាក់ចន្លោះរវាងអក្សរចិន។ អត្ថបទគ្មាន timestamp ប្រើល្បឿននិយាយ ១៤ / ៤.៦ / ៧.៥ តួក្នុងមួយវិនាទី។
- **Whisper**៖ `language = zh / ko / auto`; 中文 ប្រើ prompt “以下是普通话的句子。” (ដើម្បីបាន 简体 + វណ្ណយុត្តិ); model `tiny`/`base` ត្រូវប្តូរទៅ `small` ដោយស្វ័យប្រវត្តិ។ បើ Auto ហើយ Whisper ឮភាសាផ្សេង (ឧ. ជប៉ុន) ប្រព័ន្ធឈប់ភ្លាមៗ មិន transcribe ឥតប្រយោជន៍។
- **បកប្រែ**៖ Google `sl` = `en` / `zh-CN` / `ko` (繁體 ក៏ដំណើរការ); AI / LLM ត្រូវបានប្រាប់ឈ្មោះភាសា និងគំរូពាក្យ។
- **ពាក្យបច្ចេកទេសជា English**៖ ① ពាក្យ English ក្នុងអត្ថបទ (Docker, GPT-4, `https://…`) ដូចធម្មតា ② **តារាង 中文 / 한국어 → English** ដែលភ្ជាប់មកជាមួយ — 服务器 | 伺服器 → *server*, 数据库 → *database*, 机器学习 → *machine learning*, 谷歌 → *Google*; 서버 → *server*, 머신러닝 → *machine learning*, 유튜브 → *YouTube*, 파이썬 → *Python*, 챗GPT → *ChatGPT* ③ បន្ថែមខ្លួនឯងក្នុង *ពាក្យបច្ចេកទេស*៖ `源词 => English`។ ភាសាកូរ៉េដាក់ particle ជាប់នាម (서버를, 서버에서는) — ប្រព័ន្ធដឹង និងមិនប៉ះពាល់ពាក្យវែងជាង (서버리스 ≠ 서버)។
- **ឯកសារ SRT ភាសាដើម**៖ ឈ្មោះ `…_chinese.srt` / `…_korean.srt` / `…_english.srt`។ ការងារចាស់ (មុន v1.3) នៅបើកបាន ហើយ *Regenerate* ប្តូរ `english.srt` ទៅជា `original.srt`។

> ⚠ **ស្ថានភាពនៃការសាកល្បង៖** បានសាកល្បងពិតជាមួយ Google Translate (中文/한국어 → ខ្មែរ), សំឡេង Edge, តារាងពាក្យ, SRT គំរូ, UI និងការជ្រើស caption track (ទិន្នន័យ YouTube ពិតសម្រាប់ English + ទិន្នន័យ mock សម្រាប់ចិន/កូរ៉េ)។ **មិនទាន់បានសាកល្បង**៖ វីដេអូ YouTube ភាសាចិន/កូរ៉េពិតៗ និង Whisper ជាមួយសំឡេងចិន/កូរ៉េពិត។ សូមប្រាប់ ប្រសិនបើអ្នកជួបបញ្ហា។

### ដំឡើង (ម្តងគត់)

1. **Settings → VoxCPM2 → “ដំឡើង VoxCPM2”** (១០–៣០ នាទី · អាចបិទ Browser ព្រោះវានៅតែដំណើរការ · បើដាច់ចុចម្តងទៀត វាបន្តពីកន្លែងដែលឈប់)។ ប្រព័ន្ធ៖
   1. ពិនិត្យ GPU (`nvidia-smi`) ហើយជ្រើស PyTorch ត្រឹមត្រូវ (GPU ឬ CPU)
   2. រៀបចំ Python 3.11 **ដាច់ដោយឡែក** (មិនប៉ះពាល់ Python របស់អ្នកទេ — បើគ្មាន Python 3.10–3.12 វាទាញយក Python 3.11 តាម `uv`)
   3. ដំឡើង PyTorch + `voxcpm`
   4. ទាញយក model ៥ GB ពី Hugging Face
   5. **សាកល្បងជាក់ស្តែង** — ផ្ទុក model និងនិយាយ ១ ប្រយោគខ្មែរ រួចបង្ហាញល្បឿន
2. ក្នុងផ្នែក *Voice* ជ្រើស **VoxCPM2** → ជ្រើសសំឡេង → **Generate**។
3. Engine ចាប់ផ្តើមដោយស្វ័យប្រវត្តិ (ផ្ទុក model ១–៣ នាទីលើកដំបូង) ហើយបិទដោយខ្លួនឯងបើមិនប្រើ ៣០ នាទី។

ឬដំឡើងពី command line៖ `install-voxcpm.bat` (Windows) · `install-voxcpm.command` ចុចពីរដង (Mac) · `sh install-voxcpm.sh` (Mac/Linux) · ឬ `python -m app.vox_setup`។

**ទីតាំង៖** Windows `%LOCALAPPDATA%\KhmerDub\voxcpm` (path ខ្លីដោយចេតនា ព្រោះ PyTorch មាន folder ជ្រៅ) · macOS `~/Library/KhmerDub/voxcpm` · Linux `data/voxcpm`។ (ឈ្មោះ folder `KhmerDub` នៅដដែលបន្ទាប់ពីប្តូរឈ្មោះកម្មវិធី ដើម្បីកុំឲ្យ VoxCPM2 ដែលបានដំឡើងរួចត្រូវដំឡើងម្តងទៀត។) **លុប folder នោះ = លុប VoxCPM2 ចេញទាំងស្រុង** (រួមទាំង Designed voices ដែលបានបង្កើត — ក្នុង `voices/preset-*.wav`)។ សំឡេង *My voices* ស្ថិតក្នុង `data/voices/`។

### Clone — សូមប្រើដោយយុត្តិធម៌

- ប្រើតែ**សំឡេងរបស់ខ្លួនឯង** ឬអ្នកដែល**បានអនុញ្ញាត** — UI តម្រូវឲ្យ tick *“ខ្ញុំជាម្ចាស់សំឡេង ឬមានការអនុញ្ញាតឲ្យ Clone”* មុន Generate។ (Google និង Microsoft ក៏តម្រូវការយល់ព្រមដូចគ្នាសម្រាប់ voice cloning របស់ពួកគេ។)
- Dub តែវីដេអូដែលអ្នកមានសិទ្ធិ ហើយបង្ហាញថាសំឡេងជា AI ពេលបោះពុម្ព (YouTube មានច្បាប់ disclosure សម្រាប់ synthetic content)។
- គន្លឹះគុណភាព៖ clip ស្អាត មនុស្សម្នាក់ គ្មានតន្ត្រី ៨–២៥ វិនាទី។ វីដេអូមានអ្នកនិយាយច្រើននាក់ → Clone បានតែសំឡេងមួយ (ជ្រើស start time ឲ្យត្រូវអ្នកដែលចង់បាន)។

### My voices — ច្រើនតួអង្គ (v1.12.0)

- ជ្រើស **VoxCPM2** → ផ្នែក **សំឡេងរបស់ខ្ញុំ (My voices)** → ចុច **បន្ថែមសំឡេង** ហើយ**ជ្រើសឯកសារច្រើនក្នុងពេលតែមួយ** (Ctrl / Shift ក្នុងប្រអប់ជ្រើសឯកសារ) — ឬ**ទាញឯកសារមកទម្លាក់**ក្នុងតំបន់ VoxCPM2។ **ឯកសារ ១ = តួអង្គ ១**៖ ឈ្មោះសំឡេង = ឈ្មោះឯកសារ (ឈ្មោះដូចគ្នា → `Boy 2`)។ ឯកសារនីមួយៗ ៨–២៥ វិនាទី មនុស្សម្នាក់ ច្បាស់ គ្មានតន្ត្រី (សំឡេងពីវីដេអូ MP4 / WEBM ក៏បាន)។
- កម្មវិធី upload ម្តងមួយឯកសារ ហើយបង្ហាញ «កំពុងបន្ថែមសំឡេង ២ / ៥» រួចសង្ខេប «បានបន្ថែមសំឡេង ៤ ក្នុងចំណោម ៥» — ឯកសារណាខុស (ខ្លីពេក · មិនមែនសំឡេង · ធំជាង 30 MB) ត្រូវរាយឈ្មោះជាមួយមូលហេតុ ហើយមិនឃាត់ឯកសារផ្សេងទេ។ ឯកសារតែមួយ → ប្រអប់សួរឈ្មោះដូចមុន ហើយសំឡេងនោះត្រូវបានជ្រើស។ ឯកសារដែលបានទម្លាក់ **មិនត្រូវបាន**យកទៅជាវីដេអូសម្រាប់ Dub ទេ។
- ប៊ូតុង **✎** = ប្តូរឈ្មោះ (ឈ្មោះតួអង្គ ឧ. «ម្តាយ», «កូនប្រុស»; ≤ 60 តួ; លំដាប់ក្នុងបញ្ជីមិនប្តូរ) · **🗑** = លុប · **▶** = ស្តាប់។
- **ប្រើច្រើនតួអង្គក្នុងវីដេអូតែមួយ**៖ ក្នុងតារាង Segments ជ្រើស Voice ក្នុងមួយជួរ (ក្រុម *សំឡេងរបស់ខ្ញុំ*) ឬធីកច្រើនជួរ → ជ្រើស Voice → *ដាក់* (មើល «Voice ក្នុងមួយជួរ»)។ ចាប់ពី v1.13 កម្មវិធីស្គាល់ថានរណានិយាយ ប្រុស / ស្រី ដោយខ្លួនឯង (មើល «👥 សំឡេងតាមតួអង្គ») ហើយជម្រើស «**សំឡេងរបស់ខ្ញុំដែលត្រូវភេទ**» ប្រើតែសំឡេងដែលមានភេទត្រូវនឹងតួអង្គ។
- **ភេទរបស់សំឡេង (v1.13)**៖ ពេល upload កម្មវិធី**ស្គាល់ភេទពីសំឡេង** (តែពេលច្បាស់ — មិនបាច់ប្រាប់) → ស្លាក ស្រី / ប្រុស លើកាត; សំឡេងដែលមិនច្បាស់ (ឬ clip ខ្លីពេក) ត្រូវបានសម្គាល់ **«ភេទមិនដឹង»** ហើយមិនត្រូវបានប្រើជាមួយ «ដែលត្រូវភេទ»។ ប៊ូតុង **⇄** កែ (ស្រី → ប្រុស → មិនដឹង)។

### Quality / ល្បឿន

- **គុណភាព**: *លឿន* (6 ជំហាន) · *មធ្យម* (10 · លំនាំដើម) · *ខ្ពស់* (20) — ជំហាន diffusion ច្រើន = ធម្មជាតិជាង តែយឺតជាង។ ក្រោមប៊ូតុងមានការប៉ាន់ស្មានពេល ដែលគណនាពីល្បឿនវាស់ពេលដំឡើង (ឧ. *លឿន ≈ 0.7× · មធ្យម ≈ 1.0× · ខ្ពស់ ≈ 1.7×* នៃរយៈពេលសំឡេង)។
- **ហេតុអ្វីយឺតជាង Microsoft?** Edge TTS រត់លើ server របស់ Microsoft ហើយបង្កើតបានភ្លាម។ VoxCPM2 ជា model 2 ពាន់លាន parameter រត់លើ GPU របស់អ្នក ហើយបង្កើតសំឡេងម្តង ០.១៦ វិនាទី ក្នុងមួយជំហាន — ជាមួយ GPU កណ្តាល CPU ចំណាយពេលភាគច្រើនក្នុងការបញ្ជា GPU (GPU ប្រើតែ ~៥០%)។
- **Turbo ⚡ (ពិសោធន៍)**: Settings → VoxCPM2 → បើក *Turbo*។ វាកត់ត្រាជំហាន diffusion ជា **CUDA graph** (បញ្ជា GPU តែម្តងជំនួស ~៣០០០) ដូច្នេះអាចលឿនជាង **≈ ២×** ដោយសំឡេងដូចដើម។ វាត្រូវបានផ្ទៀងផ្ទាត់ជាមួយលទ្ធផលធម្មតាមុនប្រើ ហើយបើមានបញ្ហាអ្វីក៏ដោយ វាត្រឡប់ទៅរបៀបធម្មតាដោយខ្លួនឯង (Settings បង្ហាញមូលហេតុ)។ *ពិសោធន៍ — មិនទាន់សាកល្បងលើ GPU ពិតរបស់អ្នកទេ*៖ បើចង់ប្រៀបធៀប សូមមើល “x real time” ក្នុងលទ្ធផលការងារ មុន/ក្រោយបើក។
- **ផ្ទុក model ទុកមុន**: ពេលអ្នកជ្រើស **VoxCPM2** engine ចាប់ផ្តើមផ្ទុក model ក្នុង background ភ្លាម (ដូច្នេះឃ្លាដំបូងមិនត្រូវរង់ចាំ ២០–៦០ វិនាទី) ហើយ engine ធ្វើ *warm-up* មួយឃ្លាមុន។ វាបិទដោយខ្លួនឯងបើមិនប្រើ ៣០ នាទី។
- **Speed / Volume** — កែបាន (Speed ប្រើ time-stretch ដោយមិនប្តូរកម្ពស់សំឡេង)។ Pitch មិនមានសម្រាប់ VoxCPM2។
- ឃ្លាដែលបង្កើតរួចត្រូវ **cache** — Regenerate ឃ្លាមួយ មិនបង្កើតឃ្លាផ្សេងឡើងវិញ ហើយបើគ្រប់ឃ្លាមាន cache engine មិនចាំបាច់ចាប់ផ្តើមទេ។
- Progress បង្ហាញ `៣/១២ · ~២ min left`។ **Cancel** → ឈប់បន្ទាប់ពីឃ្លាបច្ចុប្បន្ន (បើវាយូរជាង ២០ វិនាទី engine ត្រូវបានបិទ)។
- VoxCPM2 ត្រូវការអត្ថបទយ៉ាងហោចណាស់ ~១ វិនាទី — ឃ្លាខ្លីខ្លាំង (“បាទ។”) អាចស្តាប់ខ្សោយ។
- គន្លឹះ៖ ប្រើ **Edge** សម្រាប់ព្រាងលឿន រួចប្តូរទៅ **VoxCPM2 (Clone)** សម្រាប់ជំហានចុងក្រោយ។

## 💬 Subtitle ដើម បើក/បិទ

ក្នុងលទ្ធផល **Sync Preview** មានប៊ូតុង៖

## ⚙️ ដំណើរការខាងក្នុង (How it works)

```text
YouTube link
 └─ 1. Transcript:  youtube-transcript-api  →  (fallback) yt-dlp subtitles  →  (fallback) Whisper
     │      ភាសា = ជម្រើសរបស់អ្នក ឬ Auto (captions ស្វ័យប្រវត្តិ = ភាសានិយាយ; បើមាន manual captions ច្រើនភាសា ចំណងជើងវីដេអូជួយសម្រេច)
     └─ 2. សម្អាត ([Music], [音乐], (박수), ♪ …) + បញ្ចូលជាឃ្លាពេញ (≤ ~12 វិនាទី; ប្រវែងតាមភាសា)
         └─ 3. ការពារពាក្យបច្ចេកទេស (placeholder X1X) → Google/LLM បកប្រែ (sl = en / zh-CN / ko) → ដាក់ពាក្យ English ត្រឡប់មកវិញ
             └─ 4. Edge TTS ក្នុងមួយឃ្លា: សំឡេងខ្មែរ + English Voice សម្រាប់ពាក្យបច្ចេកទេស
                 └─ 5. តម្រឹម timing: អានលឿនជាងមុនបន្តិចបើវែងពេក (≤ ×1.4) → mix
                     └─ 6. dub.mp3 + Khmer SRT + SRT ភាសាដើម + script
                         └─ 7. (ជម្រើស) yt-dlp ទាញយកវីដេអូ + ffmpeg ដាក់សំឡេងខ្មែរ → dubbed.mp4
```

> **ជំហាន 1b — ស្គាល់តួអង្គ (v1.13; YouTube / Upload ដែលមានសំឡេង)**៖ `app/speakers.py` decode សំឡេង (16 kHz) → វាស់ pitch + ពណ៌សំឡេង រាល់ជួរ → ប្រុស / ស្រី + តួអង្គ → `char` ក្នុងជួរ និង `meta.characters`; ជំហាន 4 យក Voice តាមតួអង្គ (`app/autovoice.py`)។
>
> VoxCPM2 (ជម្រើស)៖ ជំហាន 4 ប្រើ model local ជំនួស Edge — ឃ្លានីមួយៗត្រូវបានបង្កើតដោយ *reference voice* តែមួយ (ដែល upload / កាត់ពីវីដេអូ) ហើយតម្រឹម timing ដោយ time-stretch។

**ហេតុអ្វីបានជា English Voice?** យើងបានវាស់ដោយ Whisper ASR៖ សំឡេងខ្មែរអាន “API” → *“Happy / a pay”*, “Python” → *“Peace on / PAYTHON”*, “Machine Learning” → *“Matching Learning”*។ ដូច្នេះប្រព័ន្ធបំបែកប្រយោគជាផ្នែក Khmer / English ហើយអានផ្នែក English ដោយ neural voice English (Ava ឬ Andrew) រួចភ្ជាប់ជាមួយ loudness ស្មើគ្នា។

pip install -r requirements.txt -r tests/requirements-dev.txt && python -m playwright install chromium

sh tests/run_all.sh                                         # ទាំងអស់ ≈ 15 នាទី (រត់ក្នុង background ល្អជាង)
